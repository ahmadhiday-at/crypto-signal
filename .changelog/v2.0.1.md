# v2.0.1

Perbaikan routing halaman setelah route view dipindah dari `/view/...` ke root (`/:market` dan `/:market/:timeframe`).

## Diperbaiki

- **`/BTCUSDT/1h` menampilkan "Chart Error: Chart data unavailable".** Server sudah mengirim `index.html` dengan benar (HTTP 200), tetapi script di halaman masih membaca URL dengan format lama `/view/:market/:timeframe`: segmen ke-2 dianggap market dan segmen ke-3 timeframe. Pada `/BTCUSDT/1h` hasilnya market `1h` dan timeframe default `15m`, sehingga halaman memanggil `GET /api/1h/15m` → `404 unknown_market_or_timeframe`. Sekarang market dan timeframe diambil dari dua segmen terakhir URL.
- Selector market/timeframe di reference chart (`/:market/:timeframe`) dan selector market di dashboard (`/:market`) masih mengarah ke `/view/...` yang sudah tidak ada (404). Sekarang mengarah ke URL baru.

## Pengujian

- `npm test`: 73 test lulus, termasuk test baru untuk route view (`/BTCUSDT` → dashboard, `/BTCUSDT/1h` → chart; file statis dan `/api` tetap didahulukan).
- Diperiksa di browser terhadap aplikasi yang berjalan: `/BTCUSDT/1h` memanggil `/api/BTCUSDT/1h` (200), selector timeframe pindah ke `/BTCUSDT/4h`, selector market di dashboard pindah ke `/BNBUSDT`.

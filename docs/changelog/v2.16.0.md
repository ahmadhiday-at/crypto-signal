Level 6.5 B1: filter tren HTF (`against_htf_trend`) sebagai opsi config dan sweep backtest; default `off`.

**Aksi:** Tidak ada (default `off`). Opsional: `/config` → `filters.htf_trend`, lalu Run backtest.

- Tambah: `timeframes[tf].trend` (`up`/`down`/`ranging`/`unknown`, MA14 vs MA50) di Market State.
- Tambah: filter `against_htf_trend`: BUY ditolak bila TF yang dicek turun, SELL bila naik.
- Tambah: config `filters.htf_trend` = `off` / `htf` / `htf+structure` (pilihan select2 di `/config`).
- Tambah: backtest `--sweep htf_trend=off,htf,htf+structure`, `params.htf_trend`, breakdown `htf_trend`.
- Ubah: Edge `params_differ` juga membandingkan `htf_trend` (report lama = `off`).

**Tes:** `npm test` 131/131; backtest 1 tahun BTC/SOL/BNB fee 0,1% split 0,7: filter tidak memberi edge (BTC −0,24→−0,15 R, SOL −0,28→−0,92 R, BNB −0,21→−0,33 R) → tetap `off`.

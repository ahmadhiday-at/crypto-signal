# v2.14.0

Config perhitungan dipisah dari `.env` ke `config/calculation.json`, bisa diubah dari file atau halaman `/config`, plus tombol hitung ulang backtest.

**Aksi:** Restart app sekali (`docker compose restart app`, atau stop/start `node server.js`) agar `server.js` baru dan watcher config aktif. `WEIGHT_*` di `.env` kini hanya default untuk `weights`.

- Tambah: `config/calculation.json`: grup `signal` (threshold, min_rr, stop_atr, trailing_atr, htf_proximity_percent), `filters`, `weights`, `backtest` (days, fee_pct, split).
- Tambah: edit file → reload otomatis ±2 detik tanpa restart; nilai tidak valid ditolak (log), nilai lama tetap dipakai.
- Tambah: halaman `/config` (link "Config" di dashboard dan backtest), `GET/PUT /api/calc-config`.
- Tambah: hitung ulang backtest dari `/config` (per market / semua), `GET/POST /api/backtest-runs`, jalan di proses anak.
- Ubah: CLI backtest memakai config file; default `--fee 0.1 --split 0.7` (sebelumnya 0 / tanpa split), `--split none`; report `params` menyimpan nilai filter; edge `params_differ` juga membandingkan nilai itu.

**Tes:** `npm test` 129/129 (+7: config, runner, API); E2E Binance palsu: PUT config, run backtest, edit file manual → `params_differ`; browser `/config` desktop + mobile.

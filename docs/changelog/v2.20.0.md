# v2.20.0

Model sinyal baru `trend_pullback` dan `breakout` (config `signal.model`); default tetap `bounce`.

**Aksi:** Tidak ada (default `bounce`). Opsional: `/config` → `signal.model`; model tren paling baik dengan role 1h/4h/1d/1w (`.env` TF_ENTRY/TF_MID/TF_STRUCTURE/TF_HTF, `restart app`).

- Tambah: `signal.model` = `bounce` / `trend_pullback` (pullback ke MA50 entry searah tren HTF) / `breakout` (close tembus channel N candle searah tren).
- Tambah: grup config `trend` (poin tren per TF, pullback, breakout, momentum, volume, `stop_atr`, `target_r`).
- Tambah: field Market State `channel` {high, low, candles} dan kode reason baru (`htf_trend_up`, `pullback_to_ma`, `channel_breakout_up`, …).
- Tambah: backtest `--sweep model=…` dan `trend.<key>`; Edge `params_differ` membandingkan `model`.
- Tambah: roadmap Level 6.5 B4 (validasi 3 tahun) dan B5 (model baru) dengan hasilnya.

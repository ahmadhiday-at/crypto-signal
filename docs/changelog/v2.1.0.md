# v2.1.0

Dashboard `/:market` muat satu layar, pane sejajar dan sinkron, legend ala Binance. Logika state/score tidak berubah.

**Aksi:** Tidak ada (reload halaman).

- Tambah: legend per pane mengikuti crosshair (OHLC, Change/% vs Open, Range %, MA, Vol, MACD, RSI); default candle closed terakhir.
- Tambah: harga live + selisih/% vs close candle closed terakhir TF terpilih; garis RSI 30/70.
- Ubah: layout 100vh, pane ±55/15/15/15 + `ResizeObserver`; sidebar scroll internal; kartu Technical Summary dihapus; satu format angka; sumbu waktu hanya di pane bawah.
- Perbaiki: RSI tidak sejajar/terpotong → semua pane memakai waktu bar yang sama (whitespace untuk warm-up/forming).
- Perbaiki: range antar pane beda 1 bar → hanya pane di bawah mouse (atau main) yang sync; crosshair sinkron di semua pane; lebar price scale sama.

**Tes:** `npm test` 73/73; browser 1440×900 & 1920×1080: tanpa scroll, x candle terakhir sama di 4 pane, range sync dari main & RSI, tanpa error console.

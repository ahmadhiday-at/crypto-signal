Semua angka perhitungan pindah ke `config/calculation.json`: poin skor, indikator, zona S/R, ambang market state, divergence dan evaluasi trade; default = nilai lama.

**Aksi:** Tidak ada (default sama, hasil identik). Opsional: ubah di `/config`, lalu Run backtest.

- Tambah: grup config `scoring`, `indicators`, `zones`, `market`, `divergence`, `evaluation` (±50 key, form di `/config`).
- Tambah: ubah `indicators`/`zones` → semua snapshot dihitung ulang dari candle tersimpan (tanpa request Binance), juga sekali saat start.
- Tambah: validasi antar-key (MA fast < mid < slow, `min_candles` ≤ `CANDLE_LIMIT` − 1, ambang naik berurutan).
- Ubah: expiry signal log/backtest dan `min_trades` Edge/validasi dari config; report backtest menyimpan `params.calc`, Edge `params_differ` bila berbeda.
- Ubah: zona tanpa sentuhan tidak dapat bonus recency (sebelumnya sentinel 100; hasil default sama).

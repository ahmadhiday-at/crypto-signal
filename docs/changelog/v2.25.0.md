# v2.25.0

Simpan config, Run backtest dan Reset kini butuh `ADMIN_TOKEN`.

**Breaking:** `PUT /api/calc-config`, `POST /api/backtest-runs`, `POST /api/reset` tanpa token valid dijawab 401/403.
**Aksi:** Tambah `ADMIN_TOKEN` (minimal 16 karakter) ke `.env`, lalu restart app; `docker compose restart app` di Docker.

- Tambah: env var `ADMIN_TOKEN`, header `X-Admin-Token`, field `admin_configured` di `/api/config`.
- Keamanan: siapa pun yang bisa membuka app dapat mengubah config atau memicu backtest dan reset → aksi ditolak tanpa token.
- Ubah: halaman meminta token sekali per tab dan menyimpannya di `sessionStorage`.

**Tes:** `npm test` 151/151; endpoint dan alur browser diuji dengan server uji.
**Docs:** docs/contract/rest.md, docs/architecture/config.md, docs/DEPLOYMENT.md, .env.example
**Belum:** Tanpa TLS token terkirim apa adanya; belum ada batas percobaan token dan riwayat perubahan config.

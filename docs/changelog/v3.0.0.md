# v3.0.0

Market dan timeframe pindah ke `/config`; `.env` kini hanya untuk pengaturan server dan rahasia.

**Breaking:** Env var dihapus: `MARKET_LIST`, `TIMEFRAME_LIST`, `TIMEFRAME_LABELS`, `TF_HTF`, `TF_STRUCTURE`, `TF_MID`, `TF_ENTRY`, `CANDLE_LIMIT`, `MAPPING_CANDLE`, `WEIGHT_*`. Label timeframe kini dari kode.
**Aksi:** Restart app. Baris lama di `.env` boleh dihapus; selama masih ada, log startup menyebut namanya. Deployment lain: isi `engine.markets` di `/config`.

- Tambah: `engine.markets` dan `engine.timeframes` di `config/calculation.json`, bisa diedit di `/config` (perlu restart).
- Ubah: default `engine.candle_limit` jadi 1000; default `weights` dan `lookback` kini di kode.
- Tambah: validasi `shadow` harus memakai timeframe yang diambil datanya.
- Keamanan: simbol market hanya huruf besar dan angka, 5–20 karakter, maksimal 20 market.

# v4.2.0

Tampilan dirombak jadi papan sinyal Long/Short untuk trader, dengan design system sendiri di semua halaman.

**Breaking:** Tidak ada di API. `/` kini ke `/signals`, bukan ke market pertama.
**Aksi:** Tidak ada.

- Tambah: halaman `/signals` dan `GET /api/signals`: sinyal semua market, trade terbuka, hasil terakhir, alert browser.
- Tambah: halaman Market berisi sinyal LONG/SHORT/WAIT, alasan, trade plan, kalkulator ukuran posisi, garis plan di chart.
- Ubah: Backtest dan Config dikelompokkan dengan tab; refetch data dan health pindah ke Config > Operations.
- Ubah: Tailwind CDN, jQuery, select2, lucide dihapus; kode halaman pindah ke `public/js/pages/`, chart jadi satu modul.
- Ubah: default kode `shadow` mengikuti `trend_pullback` 4h; nama paket jadi `crypto-signal`.
- Perbaiki: kode mentah seperti `htf_trend_up` dan `negative_expectancy` tampil tanpa label.
- Perbaiki: semua zona berlabel STRONG dan menutupi chart; harga di Chart selalu 2 desimal; sinyal yang bertahan terbaca seperti entry baru.

**Tes:** `npm test` lulus; 5 halaman dicek di browser pada 1440 px dan 375 px dengan Binance palsu.
**Docs:** README, overview, rest, market-state, config
**Belum:** Aturan sinyal tidak diubah; BTC masih negatif setelah biaya. Alert hanya saat halaman terbuka.

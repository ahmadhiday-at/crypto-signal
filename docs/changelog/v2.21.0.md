# v2.21.0

Role timeframe, `CANDLE_LIMIT` dan `MAPPING_CANDLE` pindah dari `.env` ke `config/calculation.json` (grup `engine` dan `lookback`); nilai `.env` jadi default awal.

**Aksi:** Tidak ada wajib (nilai `.env` dipakai sampai config disimpan). Setelah simpan di `/config`, baris `TF_*`, `CANDLE_LIMIT`, `MAPPING_CANDLE`, `WEIGHT_*` di `.env` boleh dihapus. Ubah `engine` → `restart app`.

- Tambah: grup config `engine` (`htf`, `structure`, `mid`, `entry`, `candle_limit`), berlaku saat start; `/config` menampilkan nilai yang menunggu restart.
- Tambah: grup config `lookback` per timeframe (dulu `MAPPING_CANDLE`), berlaku langsung (snapshot dihitung ulang); bisa di-`--sweep lookback.<tf>`.
- Tambah: `GET /api/calc-config` → `running_engine`; backtest CLI `--roles ENTRY,MID,STRUCTURE,HTF`; Edge `params_differ` bila role report berbeda.
- Ubah: validasi role htf ≥ structure ≥ mid ≥ entry dan `indicators.min_candles` ≤ `engine.candle_limit` − 1.

**Tes:** `npm test` 144/144; E2E: simpan role 1h/4h/1d/1w → menunggu restart, setelah restart role aktif dan status `ok`.

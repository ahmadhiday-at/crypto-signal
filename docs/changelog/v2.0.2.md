# v2.0.2

Restrukturisasi dokumentasi agar hemat token: dokumen detail dipindah ke `docs/`, CLAUDE.md diringkas, dan CHANGELOG.md menjadi indeks. Tidak ada perubahan perilaku aplikasi.

## Diubah

- Dokumen dipindah: `ARCHITECTURE.md`, `DATA_CONTRACT.md` → `docs/`; `DOCKER_README.md` → `docs/DEPLOYMENT.md`; `.changelog/*` → `docs/changelog/`; riwayat ≤1.1.0 dari `CHANGELOG.md` → `docs/changelog/v1.x.md`.
- `ROADMAP.md` dan `CRYPTO AI SIGNAL SYSTEM ROADMAP.md` digabung menjadi `docs/ROADMAP.md`.
- Daftar endpoint dipindah dari README ke `docs/DATA_CONTRACT.md` (§0). `DATA_CONTRACT.md` tidak digabung ke `docs/API.md` karena dirujuk oleh komentar kode.
- Komentar di `src/services/contract.js`, `public/js/market-status.js` dan `public/market_view.html` menunjuk ke `docs/DATA_CONTRACT.md`.

## Dokumentasi

- `CLAUDE.md` — ditulis ulang: stack, perintah, arsitektur singkat, peta dokumen, aturan versi/changelog, larangan file prompt.
- `README.md` — diringkas: overview, install, run, tautan ke `docs/`.
- `CHANGELOG.md` — menjadi indeks, satu baris per versi.
- `docs/ARCHITECTURE.md` — ditambah "Code Map" dan "Configuration Notes" (dipindah dari CLAUDE.md); tautan ke `DEPLOYMENT.md`.
- `docs/DATA_CONTRACT.md` — ditambah daftar endpoint.
- `docs/ROADMAP.md` — gabungan dua roadmap.
- `docs/changelog/TEMPLATE.md` — path baru.

## Tindakan yang diperlukan

- Tidak ada untuk aplikasi. `PROMPT_AI_*.md` dan `.prompt_manual/` tidak diperiksa; jika merujuk path lama (`DATA_CONTRACT.md`, `DOCKER_README.md`, `ROADMAP.md`), perbarui manual.

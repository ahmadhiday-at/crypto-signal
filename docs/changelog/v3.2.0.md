**Aksi:** Tidak ada; snapshot dihitung ulang saat start. Laporan backtest `bounce` lama tidak lagi mewakili hasil sekarang.

- Tambah: config `zones.max_width_percent`, default 2 (lebar total, % dari harga zona).
- Perbaiki: zona 1w selebar sekitar 10% menelan level timeframe lain → dibatasi 2%.
- Perbaiki: level digolongkan terhadap close timeframe-nya, sehingga support bisa berada di atas harga → kini terhadap harga sekarang.
- Tambah: sisi yang kosong memakai low/high terbaru entry timeframe, sesuai `zones.fallback_candles`.
- Ubah: `context`, `distance`, `breakout_score`, `setup_state`, `fake_breakout_risk` dan TP2 ikut berubah.

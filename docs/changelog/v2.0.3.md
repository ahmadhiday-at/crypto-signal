Dokumentasi `docs/` dipecah menjadi file kecil per topik agar Claude hanya membaca bagian yang relevan. Tidak ada perubahan perilaku aplikasi.

- `docs/DATA_CONTRACT.md` → `docs/contract/rest.md` (endpoint + respons 503), `docs/contract/market-state.md` (kontrak §1–§7), `docs/contract/websocket.md` (baru: bentuk pesan WS dan batasannya, dari `src/websocket/ws.manager.js`).
- `docs/ARCHITECTURE.md` → `docs/architecture/overview.md` (komponen, design goals, code map), `docs/architecture/operating-model.md` (O1–O7), `docs/architecture/config.md` (tabel env var + catatan konfigurasi).
- `docs/ROADMAP.md` → `docs/roadmap/README.md` (prinsip, posisi saat ini, bot eksekusi) dan `docs/roadmap/level-{1,2,2.5a,2.5b,3,4,5,6,7}.md`.
- Komentar kode yang merujuk dokumen diperbarui: `src/services/contract.js`, `src/services/freshness.js`, `public/js/market-status.js`, `public/market_view.html`.

# v2.25.1

`.env.example` kini hanya berisi pengaturan deployment.

**Aksi:** Tidak ada; `.env` lama tetap berfungsi dan baris yang tidak terpakai boleh dihapus.

- Ubah: hapus `DEFAULT_MARKET`, `DEFAULT_TIMEFRAME`, `LOG_LEVEL` (tidak dibaca kode) dari `.env.example`.
- Ubah: hapus `TF_*`, `WEIGHT_*`, `MAPPING_CANDLE`, `CANDLE_LIMIT` dari `.env.example`; kode masih membacanya sebagai seed.
- Ubah: `lookback` masuk `config/calculation.json` dengan nilai yang sama seperti sebelumnya.
- Ubah: `BINANCE_REST_URL` dan `BINANCE_WS_URL` jadi opsional (dikomentari).

**Tes:** `npm test`; nilai config efektif dibandingkan sebelum dan sesudah.
**Docs:** .env.example, docs/architecture/config.md, docker-compose.yml, README.md

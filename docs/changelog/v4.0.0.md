# v4.0.0

History backtest disimpan per tahun, masuk git, dan diisi otomatis setiap hari.

**Breaking:** Path data berubah: `data/history/{MARKET}_{tf}.json` → `data/history/{MARKET}/{tf}/{YYYY}.json`, satu baris per candle.
**Aksi:** Tidak ada; file lama dipecah otomatis saat dibaca, diverifikasi, lalu dihapus. Commit `data/history/` agar tidak perlu mengunduh ulang di mesin lain.

- Tambah: job harian 00:01 UTC, juga sekali 60 detik setelah start untuk mengejar yang tertinggal.
- Ubah: hanya yang kurang diambil: sebelum candle pertama, lubang di tengah, dan candle terbaru; tahun yang selesai tidak ditulis ulang.
- Tambah: `meta.json` per timeframe mencatat awal data Binance dan lubang yang tidak tersedia, supaya tidak diminta lagi.
- Perbaiki: candle 1w diunduh penuh di setiap run → kini diminta sekali.
- Perbaiki: unduhan yang gagal di tengah membuang halaman yang sudah terambil → kini tersimpan.

**Tes:** `npm test` 180/180; migrasi data BTC: hash tiap timeframe sama, hasil backtest sama.
**Docs:** docs/architecture/overview.md, docs/DEPLOYMENT.md, docs/roadmap/level-5.md, CLAUDE.md
**Belum:** Job tidak meng-commit sendiri; 30m dan 1m tidak disimpan; timeframe baru diunduh saat run berikutnya.
